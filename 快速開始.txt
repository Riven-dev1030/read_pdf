🎯 最簡單的使用方式（推薦）

  Windows 用戶：
    → 雙擊「啟動PDF閱讀器.bat」

  Mac/Linux 用戶：
    → 雙擊「啟動PDF閱讀器.sh」

  ✨ 腳本會自動：
     • 檢查 Python 環境
     • 安裝必要套件
     • 啟動 GUI 程式


───────────────────────────────────────────────────────

📝 首次使用需要

  1. 安裝 Python 3.6 或更高版本
     下載地址：https://www.python.org/downloads/

  2. Windows 用戶注意：
     安裝時請勾選 "Add Python to PATH"


───────────────────────────────────────────────────────

🔧 進階選項

  想要製作完全獨立的可執行檔？
  → 請閱讀「打包說明.md」


───────────────────────────────────────────────────────

❓ 常見問題

  Q: 雙擊沒反應？
  A: 確認已安裝 Python 並添加到 PATH

  Q: 提示找不到模組？
  A: 執行：pip install pypdf

  Q: Linux 提示權限錯誤？
  A: 執行：chmod +x 啟動PDF閱讀器.sh


───────────────────────────────────────────────────────

💡 功能簡介

  單檔案模式：
  • 打開 PDF 檔案
  • 瀏覽全部內容
  • 搜尋關鍵詞（支援跳轉）

  批次搜尋模式：
  • 打開資料夾
  • 搜尋多個 PDF
  • 快速定位內容
