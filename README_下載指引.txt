📥 最簡單的下載方式

  方式 1: 直接下載 ZIP 檔
  ────────────────────────────────────────────────────
  點擊以下連結下載：
  https://github.com/Riven-dev1030/read_pdf/archive/refs/heads/claude/assess-project-status-0155G97GLB2yxBQ9NHrbfRWA.zip

  下載後解壓縮，雙擊啟動腳本即可使用！


  方式 2: 使用 Git Clone（推薦給開發者）
  ────────────────────────────────────────────────────
  git clone -b claude/assess-project-status-0155G97GLB2yxBQ9NHrbfRWA https://github.com/Riven-dev1030/read_pdf.git


───────────────────────────────────────────────────────────────

🚀 下載後如何使用

  Windows 用戶：
    1. 解壓縮下載的檔案
    2. 雙擊「啟動PDF閱讀器.bat」
    3. 完成！

  Mac/Linux 用戶：
    1. 解壓縮下載的檔案
    2. 在終端執行：chmod +x 啟動PDF閱讀器.sh
    3. 雙擊「啟動PDF閱讀器.sh」
    4. 完成！
